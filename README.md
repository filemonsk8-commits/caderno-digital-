# Caderno Digital

Primeiro protótipo funcional do Caderno Digital.

## O que funciona nesta etapa
- Criar cadernos, seções e páginas.
- Editar o conteúdo das páginas com formatação básica.
- Salvar automaticamente no armazenamento local do navegador.
- Pesquisar páginas.
- Exportar e restaurar backup JSON.
- Interface adaptável a celular, tablet e computador.

## Limites desta versão
- Os dados ficam neste navegador/dispositivo. Sincronização entre dispositivos e login ainda não estão conectados.
- A importação de arquivos OneNote (.one) ainda não está ativada na interface.
- Antes de inserir dados importantes, use regularmente **Baixar backup**.

## Publicação
O site é estático e pode ser publicado pelo GitHub Pages usando a pasta raiz da branch main.
